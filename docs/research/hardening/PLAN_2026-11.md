## Owner goals (translated, 2026-11-02)
1. Rolling train / test study (`proposal_rolling_retrain.md`).
2. A "slot panel" input: the top 50 or 100 coins in ONE sample, each coin = its own candle features (more features allowed),
   in a fixed order of slots (first F columns = slot 1, ...), coins NOT identified by name; the model outputs predictions for
   every slot.
3. Owner hypothesis: the model is weak because inputs first pass a Dense projection (`step_proj` / `patch_embed`), and deeper
   layers cannot recover what that projection threw away; feed features into the deep layers before their shape is changed.
4. Check whether the trainer actually steers the model toward a better model.
5. Fix confidence / uncertainty if still broken (T3 NIG floor; calibration role).
6. Better system structure; find and fix the bottlenecks of a model run.
7. The remaining hardening PRs (`audit_2026-10-31.md` §5; PRs 0-4 are merged in #57).
8. (added 2026-11-02, D-012) Bottlenecks of DEVELOPMENT, not only of runtime: what made agents slow, fail or need follow-up
   fixes when they changed or added something. Goal: the system gets easier to change over time instead of decaying.
9. (D-012) Remove the shared-namespace loading gradually wherever it slows agents down, while keeping flexibility: a radically
   different model (or any single part: encoder, readout, head, loss, normalizer) must plug in by matching the contract of the
   approved model (its input and output schema), then train, without edits spread across packages.
