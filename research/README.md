# research/ — فهرس الدراسات

منطقة الدراسات المستقلة (PHILOSOPHY.md §2): كل دراسة مجلد `research/<study>/` يستورد من أي شيء، ولا تستورد دراسةٌ دراسةً أخرى (المشترك يُرفع إلى حزمة كود).
الدراسات القديمة تبقى في `docs/research/scripts/`، ونقلها مهمة مستقلة مؤجلة.

## ما يجب أن يحويه مجلد الدراسة (PHILOSOPHY.md §3)

| العنصر | المحتوى |
|---|---|
| `README.md` أو `REPORT.md` | الغرض، البيانات، الحكم، وكيف يُعاد التشغيل |
| سكربتات مرقّمة `NN_name.py` | كل سكربت قابل لإعادة التشغيل، وأول docstring فيه بطاقة وحدة (`PURPOSE` / `TAGS` / `PITFALLS`، §4.1) |
| نتائج صغيرة | CSV أو MD (أقل من حوالي 1MB)؛ لا بيانات خام ولا checkpoints ولا مفاتيح |

قواعد إضافية: النتائج المسجلة لا تُعدَّل (الخطأ يُصحَّح بنسخة جديدة ويبقى الأصل موسومًا مثل `*_BUGGY_v1.csv`)، والفرضيات الجديدة تُضاف بدل تعديل القديمة.
